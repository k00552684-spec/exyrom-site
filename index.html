Deployment Protocol

// CLEAN INSTALL (FIRST TIME)
  1. Boot into TWRP Recovery.
  2. Wipe: Dalvik / ART Cache, Cache, Metadata, Data.
  3. Flash target ROM.zip package.
  4. (Optional) Flash compatible GApps & Everline Kernel.
  5. Reboot System.
// DIRTY FLASH (UPDATE)
  1. Boot into TWRP Recovery.
  2. Wipe: Dalvik & Cache only.
  3. Flash updated ROM.zip package.
  4. Reboot System.
