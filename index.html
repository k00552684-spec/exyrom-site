Flashing Instructions Guide
✕
Clean Flash (Recommended for New ROMs)
  1. Boot your device into TWRP Recovery.
  2. Go to Wipe > Advanced Wipe.
  3. Select Dalvik / ART Cache, Cache, Metadata, and Data then swipe to wipe.
  4. Go to Install and select your downloaded ROM zip file.
  5. (Optional) Flash NikGApps (if flashing a Vanilla build) and Everline Kernel (optional).
  6. Reboot to System and complete setup.
Dirty Flash (Updating Current ROM)
  1. Boot into TWRP Recovery.
  2. Go to Wipe > Advanced Wipe and wipe Dalvik / ART Cache and Cache.
  3. Go to Install and flash the updated ROM zip.
  4. (Optional) Reflash Everline Kernel if required.
  5. Reboot to System.
